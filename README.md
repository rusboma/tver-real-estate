# Недвижимость Твери — Scout

Сборщик запускается в Render каждые 15 минут и передаёт новости в защищённую Supabase Edge Function `agent-scout-ingest`.

## Подключённые источники

- Афанасий Бизнес: `https://www.afanasy.biz/rss/yandex_rss_news.xml`
- ТВТверь: `https://tvtver.ru/?yandex_feed=news`
- Тверская городская Дума: `https://www.tverduma.ru/news/rss.php`
- ГУ МЧС России по Тверской области: `https://69.mchs.gov.ru/deyatelnost/press-centr/vse_novosti/rss`

RSS, Telegram и страницы новостей собираются отдельными адаптерами. Источники с `disabledReason` и записи без настроенного адаптера пропускаются. Ограничения сайтов не обходятся.

## Обработка

Материалы за последние 14 дней проходят предварительный тематический фильтр, затем ограничение двадцатью материалами на источник. Новости без даты и старые архивные записи пропускаются. Ошибка одного источника не прерывает остальные; ошибка всех источников завершает запуск с ненулевым кодом.

Полный текст RSS и фотография сохраняются отдельно от анонса. Дубли по ссылке удаляются внутри запуска и при записи в базу. Повторный сбор не меняет редакторское решение. Последующая оценка в базе распределяет новости по очередям.

## Настройка

Проверка: `npm ci`, затем `npm test`. Запуск: `npm run scout`.

Серверные переменные: `SCOUT_INGEST_URL`, `SUPABASE_SERVICE_ROLE_KEY`. Секреты не коммитятся. `SCOUT_MAX_AGE_DAYS` по умолчанию равен 14. Конфигурация Render находится в `render.yaml`.

SQL атомарного импорта: `sql/scout-ingest.sql`. Edge Function: `supabase/functions/agent-scout-ingest/`. RPC доступен только `service_role`, Edge Function проверяет серверный ключ.

Telegram-публикация отключена. Сбор и одобрение новости не отправляют её в Telegram.

## Судебные и надзорные сообщения

Подключены основной и районный новостные разделы прокуратуры Тверской области. HTML-адаптер отбирает заголовки о ЖКХ и жилье, проверяет дату и сохраняет официальный полный текст. Между запросами к сайту выдерживается не менее 30 секунд согласно robots.txt. Сбор ограничен первыми страницами разделов; темы, не отражённые в заголовке, могут быть пропущены. Пресс-релиз прокуратуры может описывать поданный иск, а не вступившее в силу решение: редактор проверяет формулировки по оригиналу.

## Telegram

Публичные страницы шести каналов: прокуратура Тверской области, Тверская Телега, Новый Город, ЖКХ Ньюс, Иллидиум и Жилищный инспектор. Только тексты не короче 100 символов за последние 14 дней. Для федеральных ЖКХ Ньюс и Жилищного инспектора требуется отдельное упоминание города или района Тверской области. Совпадения внутри слов «подтвердил» и «четверг» не считаются географией. Для застройщика рекламные публикации пропускаются, если нет сообщений о строительстве или вводе дома. Смешанные публикации остаются для редакторской проверки. Все Telegram-материалы направляются на проверку. Ссылки на посты сохраняются, фото и видео пока не загружаются. Читается доступная публичная страница без обхода ограничений.

## Источники Тверской области

Каталог новых источников и причины паузы: [docs/regional-sources.md](docs/regional-sources.md). Настройки адаптеров: `src/regional-sources.js`.

Региональные сайты читаются через официальные RSS или открытые страницы новостей. Перед сбором проверяется robots.txt, учитываются запреты и Crawl-delay. При недоступности robots.txt сбор прекращается, кроме ответа 404/410. У новых источников нет автоматической публикации: материалы поступают в «На проверку». Тематический фильтр отсеивает явно посторонние школьные, медицинские и культурные темы; редактор подтверждает окончательную релевантность.

HTML-адаптер читает первые страницы, максимум восемь тематических ссылок (у Вышнего Волочка — три, Торопца — четыре, «Селигера» — две), без архивного обхода. Он сохраняет доступный полный текст и ссылку на изображение отдельно от краткого описания. Если публикация состоит из изображения, сохраняется это изображение и явное пояснение об отсутствии развёрнутого текста. Если ни текст, ни содержательное изображение недоступны, остаются анонс и ссылка на оригинал. Сайты без свежих тематических новостей остаются в сборе; отсутствие новостей не считается ошибкой.

## Повторы и публикация

Добавлена защита от одинаковых ссылок, одинаковых текстов и возможных повторов одного события из разных источников. Кабинет показывает фильтр «Повторы» и связанные материалы; основной источник или существенное обновление подтверждается редактором с пояснением. Проверка одобрения и резервирования публикации выполняется на сервере. Подробности: [docs/duplicate-protection.md](docs/duplicate-protection.md). Telegram по-прежнему отключён.
